# Bad Apple
Bad Apple where each pixel is a miku artwork. Art changes with impact points in the music.

OpenGL for rendering and FMOD for audio.

## How to Build
Tested with MSVC and Clang 21

### Windows
Opepn the project as cmake folder in Visual Studio > F5.
### Linux
Use the provided files in /scripts.
- build.sh : Incremental build
- cleanbuild.sh : Clean build
- run.sh : Run the build
